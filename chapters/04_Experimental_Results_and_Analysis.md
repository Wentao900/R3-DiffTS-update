# 4 实验结果与分析

## 4.1 证据范围与分析边界

本章围绕《多模态时间序列预测的结构化残差扩散方法》的实验结果展开，但论证范围严格限定在当前仓库中已经落盘且可追溯的真实运行资产。依据 `tables/socialgood_real_results.csv` 与 `tables/socialgood_grouped_results.csv`，目前已完成分组聚合、且可直接复核的结果主要来自 SocialGood 数据域，配置组包括 plain、notext、scorehack、backbone_coarse 与 conservative。第 3 章已经说明本研究在 benchmark 层面覆盖了多个数据域，但跨域聚合统计尚未在当前资产中形成同等完备的对照汇总，因此本章的定量分析聚焦于证据最完整的 SocialGood 设置。

这一处理遵循可验证写作原则。本文前两章确立的两条贡献主线分别是结构化残差扩散主干与结构化文本证据利用。若在证据尚未同质化汇总的情况下直接给出跨域数值排名，容易把“实验可运行性”与“量化可比较性”混为一体。基于此，本章只对已分组聚合的 SocialGood 结果做明确数值分析，对 benchmark 全域层面的信息仅保持设置层说明而不外推未经统一统计支撑的结论。全文比较也遵循两个约束：一是始终区分“分组均值行为”与“最佳单次运行行为”，二是所有结论只服务于结构化残差扩散与结构化文本证据两条贡献主线，不把校准器、控制器、辅助头和保守策略提升为创新主体。

## 4.2 SocialGood 分组总体比较

当前分组结果显示，五个配置组的样本数并不一致：plain 为 6 次运行，notext 为 5 次运行，scorehack 为 4 次运行，conservative 为 2 次运行，backbone_coarse 为 1 次运行。样本数差异意味着不同组的均值稳定性不同，解读时需要同时关注均值、极值区间与组内波动。基于 `tables/socialgood_grouped_results.csv` 与本章约束中给定的聚合摘要，五组的均值表现可写为：plain 的 CRPS_mean 为 0.180450866097、MSE_mean 为 1.378459949903、MAE_mean 为 0.670870706401；notext 的 CRPS_mean 为 0.172124734678、MSE_mean 为 1.173905884480、MAE_mean 为 0.639917091991；scorehack 的 CRPS_mean 为 0.147703898580、MSE_mean 为 0.962174203824、MAE_mean 为 0.544939111370；backbone_coarse 的三项均值分别为 0.274744887101、1.507823173390、0.956032217011；conservative 的三项均值分别为 0.311060014524、3.346510331760、1.217857122421。

如果仅按当前分组均值排序，scorehack 在 CRPS、MSE 与 MAE 三个指标上都处于最优，notext 次之，plain 再次，backbone_coarse 与 conservative 显著落后。这一结果可以支持“在当前已聚合的 SocialGood 设置中，scorehack 具有最佳平均分组表现”的事实性陈述。同时也应看到，最优均值并不自动等于最优单次。按最佳单次运行记录，notext 的 best_MSE 为 0.8909893377806789，来自 `forecasting_SocialGood_20260430_024715`；scorehack 的 best_MSE 为 0.9149576030498328，来自 `forecasting_SocialGood_20260430_083254`。这说明在 MSE 指标上，notext 出现过更低的单次误差，而 scorehack 在均值上更稳健。与之对应，scorehack 的 best_CRPS 为 0.14022987767269737、best_MAE 为 0.515796234441358，均优于 notext 的 best_CRPS=0.1455630377719277 与 best_MAE=0.5411661059357399。由此可见，均值优势与单次优势并非总是同向，后续讨论必须区分“总体表现”与“峰值表现”。

从组内波动看，plain 的区间跨度相对明显，CRPS 在 0.161960739838 到 0.217937845933 之间，MSE 在 1.137967584207 到 1.720800569353 之间，MAE 在 0.602130767911 到 0.810236579688 之间，显示该组存在由点估计策略或训练随机性带来的性能差异。notext 的跨度同样可见，MSE 介于 0.890989337781 与 1.692887192549。scorehack 的四次运行集中度相对更高，CRPS 从 0.140229877673 到 0.151258744692，MSE 从 0.914957603050 到 1.066809892308，MAE 从 0.515796234441 到 0.563937227855，整体波动窄于 plain 与 notext。当前证据可据实表述为：在 SocialGood 的已分组运行中，scorehack 体现了更好的平均水平与更紧的误差区间，但在单次 MSE 最低点上 notext 略占优势。

## 4.3 主贡献分析：结构化残差扩散主干的有效性

主贡献对应的方法命题是“结构化残差扩散更适合当前多模态时间序列预测任务”。在现有配置链路中，plain 可作为不启用结构化残差扩散主干、且不使用结构化文本证据的参考组；notext 保留结构化残差扩散主干但关闭结构化文本证据；scorehack 则在保留主干基础上进一步启用结构化文本证据及相关推理策略。因而，plain 与 notext 的对照最直接承载主干有效性的识别，而 plain 与 scorehack 的差异可作为“完整系统相对参考组”的辅助观察。

先看 plain 与 notext 的分组均值对照。CRPS 从 0.180450866097 下降到 0.172124734678，绝对下降 0.008326131419；MSE 从 1.378459949903 下降到 1.173905884480，绝对下降 0.204554065423；MAE 从 0.670870706401 下降到 0.639917091991，绝对下降 0.030953614410。按相对幅度计算，notext 相比 plain 在当前分组均值上约获得 4.61% 的 CRPS 改善、14.84% 的 MSE 改善与 4.61% 的 MAE 改善。由于二者都关闭了结构化文本证据路径，这组改进可以较为直接地支持主干层面的结论，即即使不依赖文本证据，结构化残差扩散主干也能在 SocialGood 当前证据集上带来可观的平均误差下降。

再看最佳单次运行。plain 的 best_MSE 为 1.1379675842070764，notext 的 best_MSE 为 0.8909893377806789，前后差值约 0.246978246426；plain 的 best_CRPS 为 0.1619610159020675，notext 的 best_CRPS 为 0.1455630377719277；plain 的 best_MAE 为 0.602131396301033，notext 的 best_MAE 为 0.5411661059357399。单次最优层面同样显示 notext 优于 plain。均值和最佳单次在同方向变化，使“主干有效”这一判断在当前 SocialGood 资产中具有相对一致的证据支持。

把 scorehack 加入 plain 的对照，可以观察完整配置相对参考组的整体提升幅度。scorehack 相对 plain 的均值改进为：CRPS 约下降 18.15%，MSE 约下降 30.20%，MAE 约下降 18.77%。这组数字体现了“完整系统”在当前分组上的显著优势，但从归因角度不宜直接把全部提升都归结于文本证据或某一单独机制，因为 scorehack 与 plain 同时存在主干、文本与评估策略层的多项差异。故在贡献映射上，本文保持保守表述：plain→notext 是主干效应的核心证据链，plain→scorehack 主要用于说明完整方案对参考组的总体改善规模。

基于上述对照，本章可以得出一个稳健但不夸大的判断。当前可追溯结果支持结构化残差扩散主干在 SocialGood 任务中的有效性，表现为平均误差降低与最佳单次改进同时出现。该判断的适用范围限于当前分组证据，不外推到尚未同质聚合的跨域统计。

## 4.4 次贡献分析：结构化文本证据的增益边界

次贡献对应的问题是“在保留结构化残差扩散主干的前提下，结构化文本证据是否带来额外收益”。这一命题的直接实验映射是 notext 与 scorehack 的对照。两组都保留主干结构，主要差异在于 scorehack 启用了结构化文本证据链路及其相应推理配置，而 notext 关闭文本证据路径。

从分组均值看，scorehack 相对 notext 的三项指标全部改善。CRPS_mean 从 0.172124734678 降至 0.147703898580，绝对下降 0.024420836098；MSE_mean 从 1.173905884480 降至 0.962174203824，绝对下降 0.211731680656；MAE_mean 从 0.639917091991 降至 0.544939111370，绝对下降 0.094977980621。按相对幅度估计，scorehack 在均值层面约获得 14.19% 的 CRPS 改善、18.04% 的 MSE 改善与 14.84% 的 MAE 改善。由此可支持的结论是：在当前 SocialGood 分组结果中，加入结构化文本证据的配置在平均意义上优于关闭文本证据的配置。

最佳单次运行呈现了更细的差异结构。scorehack 的 best_CRPS=0.14022987767269737 与 best_MAE=0.515796234441358 均好于 notext 的 best_CRPS=0.1455630377719277 与 best_MAE=0.5411661059357399；但在 MSE 指标上，notext 的 best_MSE=0.8909893377806789 略低于 scorehack 的 0.9149576030498328。该现象说明结构化文本证据在当前资产中更稳定地改善了分布质量与平均绝对误差，并在总体均值上同时改善 MSE，但并未在单次极值上对 MSE 形成绝对统治。这与多模态系统常见的“平均收益增强、局部峰值受随机性与策略耦合影响”现象一致，也强化了本章关于“均值与单次需分离解读”的原则。

结合 `tables/socialgood_real_results.csv` 可进一步观察两组内部运行形态。notext 中存在较低误差运行，也存在 MSE 较高的运行；scorehack 的四次运行集中在相对较窄区间，表现出更好的组内稳定度。若从部署视角看，均值与方差通常比单次最优更接近真实运维收益，因此 scorehack 的平均优势具有实际意义。若从“是否存在某些场景不依赖文本也能达到很低 MSE”的角度看，notext 的最优单次也提示了文本增益并非在每次训练中都会转化为最小平方误差，这种细节差异同样应被保留，而不应被平均结论抹平。

因此，关于次贡献的表述可保持为：当前分组证据支持结构化文本证据在保留主干条件下带来稳定的平均增益，尤其体现在 CRPS 与 MAE，并在 MSE 均值上保持改进；但在最佳单次 MSE 上，notext 仍出现了略优个例，说明文本增益属于总体趋势而非每次运行的硬性上界优势。

## 4.5 补充组观察：backbone_coarse 与 conservative

backbone_coarse 与 conservative 在当前结果体系中的定位是补充观察组，不用于定义核心创新。证据充足性方面，backbone_coarse 仅有 1 次运行，conservative 仅有 2 次运行，样本规模不足以支撑稳定的统计结论，尤其不宜用于与 4 至 6 次运行的主比较组做强结论排名。

backbone_coarse 的单次结果为 CRPS=0.274744887101、MSE=1.507823173390、MAE=0.956032217011，对应均值、最小值和最大值相同。从数值上看其表现弱于 plain、notext 与 scorehack。由于该组只有一次观测，本章只能将其解释为“在当前这一次配置与训练实例下，未显示出优于主比较组的性能”，不能进一步推导辅助头机制在该任务上的普遍效果，更不能据此否定任何单个模块的潜在价值。

conservative 的两次运行差异较大，CRPS 从 0.234494560643 到 0.387625468405，MSE 从 1.288269207459 到 5.404751456061，MAE 从 0.811270599217 到 1.624443645625，均值被高误差运行显著拉高，形成 CRPS_mean=0.311060014524、MSE_mean=3.346510331760、MAE_mean=1.217857122421。该组内部方差显著，说明其策略组合在当前样本上稳定性不足。与此同时，conservative 的 best_MSE=1.288269207459 仍显著好于其最差运行，提示该策略并非不可用，而是对训练或数据扰动更敏感。基于仅两次运行的证据，本章只能给出“高波动、低稳定”的现象描述，不能得出机制层面的确定性优劣结论。

把两组放回本文主线后可以看到，它们承担的是边界信息角色：一方面提醒读者某些增强与保守策略在小样本条件下可能引入更高不确定性，另一方面也说明工程机制的效果依赖配置耦合与运行条件。由于本文贡献主轴并不建立在这些策略上，这些观察不会改变本章对主贡献与次贡献的核心判断。

## 4.6 本章结论

在严格限定为当前可追溯 SocialGood 分组证据的前提下，本章形成了与前文一致的两点结论。第一，结构化残差扩散主干在不依赖结构化文本证据时已经体现出有效性，plain 与 notext 的均值与最佳单次对照均给出同向改进，支持主贡献成立。第二，在保留主干后引入结构化文本证据，scorehack 相比 notext 在当前分组均值上进一步改善 CRPS、MSE 与 MAE，并在最佳单次 CRPS 与 MAE 上占优，支持次贡献在平均意义上的增益；同时，最佳单次 MSE 由 notext 略优，提示该增益不是每次运行都转化为单指标极值优势。

对于 backbone_coarse 与 conservative，本章仅保留补充性、谨慎性解释：前者样本数为 1，后者样本数为 2 且组内波动大，二者不足以承担创新层结论。综合当前证据，本文的主要实证支撑仍应锚定在“结构化残差扩散主干有效”与“结构化文本证据在主干上提供平均增益”这两条链路上。该结论与本研究在方法章节确立的主次贡献保持一致，也为后续结论章节提供了可核验的实证闭环。
