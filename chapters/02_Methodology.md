# 2 方法

## 2.1 章节目标与问题定义

本文方法章节围绕“输入到输出”的技术链条展开，目标是在真实代码实现可追溯的前提下，回答多模态时间序列预测中的两个核心问题：在文本覆盖不完整、文本质量波动、文本与数值弱对齐并存的条件下，如何构建稳定的预测主干；在保证主干稳定的同时，如何让文本信息以可控方式产生增益。与这一目标对应，本文将创新层级固定为两条主线。主线是结构化残差扩散，次线是结构化文本证据。实现中的控制器、校准器、辅助头与策略变体参与训练稳定化或推理稳健性，不承担方法主体的理论地位。

设历史窗口长度为 \(L\)，预测长度为 \(H\)。对每个样本，数据层输出数值观测序列 \(X\in\mathbb{R}^{(L+H)\times D}\)、观测掩码 \(M\)、条件掩码 \(C\)、时间索引 \(T\)，并提供与历史窗口对齐的文本相关输入，包括组合文本、检索文本、趋势假设文本、事件级文本与结构化证据向量。模型输出未来区间 \([L+1, L+H]\) 的条件分布样本，进而形成点预测与概率评估。该定义与 `data_provider/data_loader.py` 的 `__getitem__` 返回字段、`main_model.py` 的 `process_data` 解包逻辑以及 `impute` 的采样输出严格一致。

从工程入口看，`exe_forecasting.py` 不是简单配置加载脚本，而是把参数融合、数据驱动统计、模型构建与评估选择串成完整实验流程。脚本在解析 YAML 与命令行参数后，会统一写回模型与训练配置，包含文本开关、时间步嵌入维度、扩散采样步数、RAG/CoT 选项、多分辨率 horizon 以及可靠性统计。随后调用 `dataset_forecasting.py:get_dataloader` 获取 train/valid/test loader，并由训练集统计结果解析多分辨率目标。这个过程决定了模型并非在静态超参数上训练，而是在数据统计约束下形成目标结构。方法章节的后续推导正是沿着这一真实链路展开。

## 2.2 输入表示与数据构造流程

输入构造起点位于 `dataset_forecasting.py`。当任务类型为 `multimodal`，函数 `get_dataloader` 通过 `data_provider.data_factory.data_provider` 实例化 `Dataset_Custom`，并返回标准化器与均值方差张量，供训练损失与评估反归一化使用。`Dataset_Custom` 在 `__read_data__` 中同步读取数值表与文本表，执行时间排序、训练验证测试切分、特征选择、缺失处理与标准化。默认目标变量来自 `target`，协变量可按配置启用。该设计保证了数值主通道的稳定性，文本通道在此基础上按时间窗口附着。

窗口生成时，样本由历史段 \([s,s+L-1]\) 与未来段 \([s+L,s+L+H-1]\) 拼接为统一 `observed_data`。与纯单变量预测不同，实现会在未来区域保留目标特征掩码并清零非目标协变量，使模型聚焦目标预测而非泄漏未来协变量信息。`observed_mask`、`gt_mask` 在这个阶段同步构造，分别对应可见性与条件采样边界。时间戳特征 `timesteps` 按频率编码后拼接到整段序列，后续进入侧信息分支。该过程直接对应 `data_loader.py` 的 `__getitem__` 与 `main_model.py` 的 `get_side_info`，形成“样本构造—掩码定义—侧信息编码”的连续输入路径。

文本输入并非一次性字符串拼接，而是窗口级检索与加工流水线。`collect_text` 会从报告表中抽取与历史窗口对齐的文本片段，标记覆盖数量、近期密度、最近文本新鲜度、原始事件列表等元信息，并在 `max_text_tokens` 预算内截断。若训练中触发 `text_drop_prob`，样本可被随机置为无文本，用于增强鲁棒性并防止模型把文本存在性当作捷径信号。到这一阶段，数据层已经提供“原始文本+窗口元信息”的中间表示，为后续结构化证据构建打下基础。

若开启 `use_rag_cot`，样本会进入 `utils/rag_cot.py` 的 `RAGCoTPipeline`。流水线先基于数值摘要与基础文本构造查询，执行检索，随后根据配置走单阶段或双阶段路径。双阶段路径先生成趋势假设文本，再用该假设重写检索查询以得到更贴近预测任务的证据集合。`build_guidance_text` 输出 `retrieved_text`、`cot_text`、`composed_text` 与记录级检索结果，并在内存和磁盘缓存中复用，避免重复生成造成的训练抖动与开销。需要强调的是，这一路径属于输入构造，不直接决定预测函数形式；其作用是把原始文本转化为更可计算的证据候选。

多分辨率 horizon 也在输入阶段被确定。`exe_forecasting.py` 的 `resolve_multi_res_horizons` 按“显式配置→训练集 ACF 统计→比例回退”顺序解析 horizon 集合，并计算 lag 级与 segment 级可靠性。这样得到的 `multi_res_horizons`、`multi_res_horizon_reliabilities`、`multi_res_segment_reliabilities` 被写回训练配置，再传入模型。该机制意味着预测目标并非固定在单一时间尺度，模型训练时同时接收“未来段划分结构”与“划分可靠性先验”，为后续残差学习提供更细粒度的监督边界。

## 2.3 结构化文本证据构建

本文次创新是结构化文本证据。它不是额外增加一个文本编码器，而是在数据层把文本从自然语言片段转化为可参与预测决策的证据向量与事件包。实现中，这个过程由 `Dataset_Custom` 内的一组函数完成，核心包括文本质量评估、趋势字段抽取、跨源一致性计算、事件触发强度估计与窗口证据聚合。

文本质量评估函数 `_compute_text_quality` 将质量分解为可得性、信息性、与数值趋势对齐度以及来源信任度四部分。可得性由 token 数估计，信息性由内容词比例、关键词覆盖与词汇多样性组合，对齐度通过数值趋势字段与文本趋势字段的匹配程度计算，来源信任度区分 raw/ret/cot 三源并受配置控制。三源质量再按 `text_quality_weights` 聚合为总质量分数，并根据阈值形成分级门控。门控策略并不改变预测目标，只约束证据通过强度，使低质量文本无法以同等权重影响模型。

趋势字段抽取采用轻量语义规则与数值统计并行实现。数值侧 `_infer_numeric_trend_fields` 从历史序列估计方向、强度、波动等级；文本侧 `_infer_text_trend_fields` 从关键词模式解析同构字段。二者交叉得到对齐评分，并在 `_build_text_trend_components` 中把 raw/ret/cot 三源趋势向量按质量与源权重聚合，形成 `trend_prior_text`。同一函数保留每个来源的向量表示，供窗口证据一致性计算使用。这样，文本趋势不再以整段句子直接进入模型，而是以与数值趋势同维的结构字段参与后续路由。

窗口证据向量 `_build_window_evidence` 将文本通道压缩为七维统计：总质量、近期覆盖密度、新鲜度、相对新颖性、跨源方向一致性、序列状态突变强度、事件触发强度。其中新颖性通过 Jaccard 距离评估 raw 与 ret/cot 的增量信息，一致性通过多源方向匹配估计证据冲突度，状态突变由数值窗口前后分布变化计算，事件触发由领域关键词激活统计得到。该七维向量以 `text_evidence_vec` 写入 batch，成为模型中“文本可用性与有效性”的统一数值接口。

事件级证据由 `_build_text_events` 构造。函数会将原始报告事件、检索记录与 CoT 文本整理为最多 `max_text_events` 条条目，每条带有来源编号、相对预测起点的时间间隔、六维质量特征与存在掩码。六维特征包含源信任、时效衰减、信息性、新颖性、对齐度与事件性。该事件包与窗口证据向量共同形成“粗粒度统计+细粒度事件”的双层文本表示。模型主路径目前主要使用窗口向量与文本池化表示，事件包更多服务于兼容扩展与未来增强，但其构造逻辑已经完整落地并在 batch 字段中可追溯。

RAG/CoT 在此框架中的角色同样保持边界清晰。`RAGCoTPipeline` 的检索与趋势假设生成提升了候选文本的任务相关度，双阶段检索通过“数值摘要→初检索→趋势假设→再检索”实现证据重排。即便本地生成模型不可用，代码也提供模板回退，确保结构化证据流程不会中断。这个设计解释了本文“结构化文本证据优于原始文本拼接”的方法依据：关键收益来自证据结构化与质量约束，而非依赖某个大语言模型本身。

## 2.4 结构化残差扩散预测框架

本文主创新是结构化残差扩散。其核心思想是把未来预测拆为模式基线与残差生成两部分，再用扩散模型专门学习残差分布。该思想在 `main_model.py` 的 `calc_loss` 与 `impute` 中以同构流程实现，训练和推理采用同一分解逻辑。

给定标准化后的观测序列 \(X\) 与条件掩码 \(C\)，模型先由 `_compute_pattern_outputs` 构建模式信息。步骤一，`_compute_pattern_stats` 从历史段提取结构统计，包含趋势拟合强度、趋势解释度、短滞后相关、季节性强度、状态稳定度、均值回归指标、事件冲击指标与归一化波动指标。步骤二，`_compute_pattern_text_evidence` 将 `text_evidence_vec` 与文本池化表示映射到专家路由证据，若配置关闭 `pattern_text_evidence` 则该分支置零。步骤三，数值路由与文本路由分别得到 `numeric_logits` 与 `text_logits`，再按指导强度融合为最终路由分布 \(\pi\)。指导强度可由自动机制估计，也可由固定 `guide_w` 指定。

基线生成由 `_build_pattern_baselines` 和 `_build_expert_futures_from_history` 完成。模型构建五类专家未来：趋势外推、季节片段重组、状态保持、均值回归、事件延续。它们都由历史段计算得到，不使用未来信息。路由分布 \(\pi\) 对专家未来加权混合，得到模式基线 \(B\)。`_compute_pattern_reliability` 再给出样本级可靠度 \(\rho\)，用来在混合基线与保守安全基线之间插值，避免在高噪声样本上过度相信复杂路由。于是未来预测对象被重写为残差
\[
R = X - B.
\]
扩散模块并不直接生成完整 \(X\)，而是针对 \(R\) 做去噪学习与采样。

在训练阶段，`calc_loss` 先对残差目标执行前向加噪，再调用 `diffmodel` 反推去噪输出 \(\hat R\)。主损失由目标区域的残差误差给出，等价于在条件掩码定义的未来区间最小化
\[
\mathcal{L}_{main}=\|R-\hat R\|^2_{\Omega},
\]
其中 \(\Omega\) 由 `target_mask` 指定。预测重组为 \(\hat X=\hat R+B\)。在推理阶段，`impute` 采用 DDIM 或标准反向扩散循环采样残差样本，并在末端加回基线得到完整预测样本。该流程在 `calc_loss` 与 `impute` 中完全对齐，避免了“训练预测对象”和“推理生成对象”不一致的问题。

结构化残差扩散的优势来自职责分解。数值历史主导基线建模，文本证据通过路由影响基线形状与残差难度分布，扩散模块专注刻画高不确定偏差。文本质量不足时，路由证据与可靠度会抑制文本增益，模型可退化为以数值结构为核心的预测；文本质量较高时，文本证据提升路由选择精度，使扩散残差在局部转折与事件扰动处更具针对性。这种“可退化、可增强”的特性正是多模态场景中稳定性的来源。

为了避免概念混淆，需要明确区分主体与增强。`main_model.py` 中还存在 `forecast_policy_controller`、coarse/uncertainty 辅助头、多项 budget 约束、自动 guidance 估计等实现，它们在训练稳定化与采样预算控制上有效，但不改变“基线+残差扩散”这一主干形式。也就是说，即使移除这些增强项，只要保留模式基线构造、残差目标定义与扩散生成，方法主体仍然成立。

## 2.5 训练与推理策略

训练策略由 `exe_forecasting.py` 与 `main_model.py` 共同定义。入口脚本负责把数据统计信息写回配置，模型负责执行主损失与辅助损失优化。优化对象仍是扩散预测主损失，辅助项仅在受控预算内加入。`calc_loss` 中的 `auxiliary_loss_max_ratio` 对辅助损失进行上限裁剪，防止辅助分支压制主目标，这一点直接体现了“增强服务主线”的设计原则。

多分辨率监督 `_calc_multi_res_loss` 是训练中的重要稳定机制。它以 `multi_res_horizons` 为边界在未来段构造分层子区间，对每个区间计算 Huber 或 MSE 误差，再按动态权重聚合。权重来源于时间步置信度、训练进度、趋势调制、区间可靠性与难度 EMA。该机制强化了不同预测跨度的误差可见性，使模型不会只优化某一局部 horizon。由于 horizon 与可靠性来自训练集统计解析，监督结构与数据域特征保持一致，提升了跨样本稳健性。

模式辅助损失 `_calc_pattern_aux_loss` 主要约束路由分布与伪标签分布的一致性，并对专家未来误差进行加权。该项在 `final_method` 下也受预算调节，避免对主损失造成过大牵引。coarse 与 uncertainty 辅助头若被配置启用，也只作为附加误差项并受统一裁剪。该设计与本文贡献层级一致：辅助路径提高训练可控性，不改写结构化残差扩散的核心建模命题。

推理策略同样遵循“主线优先、增强可选”。`impute` 先构建模式基线，再对残差执行反向扩散采样，并回到原尺度输出样本集合。若配置允许 classifier-free guidance，`exe_forecasting.py` 会在验证集或测试集上扫描 `guide_w` 并以 MSE 选择最佳值；若启用 `guide_mode=auto`，则由模型内部依据文本质量、路由一致性与文本增益估计样本级 guidance 强度。两种方式都不改变基线与残差的分解关系，只改变文本引导幅度。

评估后处理中可选 `fit_forecast_calibrator` 对点预测做轻量校准，校准参数在验证集拟合，并在最终评估中应用。该步骤位于 `exe_forecasting.py` 的评估阶段，属于输出后处理，不是预测函数主体。本文将其视为工程稳健化设计，与主创新保持严格区分。

为了让方法边界更清晰，本文在配置层也提供了可对照变体。`socialgood_36_12_notext.yaml` 通过 `pattern_text_drop_prob:1.0` 等设置压制文本影响，用于验证文本证据贡献；`socialgood_36_12_plain.yaml` 与 `socialgood_36_12_backbone_coarse.yaml` 分别对应简化主干与带辅助头对照。它们服务于实验分析，不改变章节中定义的主方法流程。

## 2.6 本章小结

本章从代码可追溯的视角给出了完整方法链条。输入端通过 `Dataset_Custom` 将数值窗口、文本片段、检索结果、趋势假设、事件包与质量统计统一组织，形成可计算的多模态样本。中间层以结构化文本证据替代原始文本直连，将文本信息压缩为趋势先验与窗口证据向量，显式处理覆盖、时效、对齐与冲突。预测层采用结构化残差扩散，把未来序列分解为模式基线与残差生成，扩散模型只负责残差分布学习并在采样阶段重组输出。训练与推理中出现的多分辨率权重、控制器、校准器与辅助头被限定为稳定化策略，不上升为主贡献。

沿着这一路径，本文的主次创新关系保持稳定：结构化残差扩散是预测建模主线，结构化文本证据是提升多模态有效性的关键支撑。两者共同作用于“稳定预测主干与可控文本增益”这一目标，为后续实验章节的对照分析提供了明确方法依据。
