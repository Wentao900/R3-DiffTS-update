# 架构图产出说明

本目录提供两张方法架构图的 Mermaid 源文件，可直接用于 Mermaid 在线编辑器、支持 Mermaid 的 Markdown 工具，或作为 draw.io / PPT 重绘底稿。

## 文件列表

- `overall_framework.mmd`：总框架图
- `text_evidence_pipeline.mmd`：文本证据构建图

## 图 1：总框架图（overall_framework.mmd）

### 论文中的推荐标题
结构化文本证据驱动的残差扩散预测框架

### 图意
这张图用于概括全文主线，突出三层结构：
1. 输入层：历史数值、时间特征、历史文本
2. 主体方法层：结构化文本证据构建 + 结构化残差扩散预测
3. 支持层：多分辨率监督、自动引导、点预测校准

### 强调点
- 文本不是直接拼接到最终预测器，而是先被转化为结构化证据。
- 预测不是直接生成未来序列，而是先得到模式基线，再学习残差。
- controller / calibrator / 辅助头等不应画成主体模块，建议画成灰色支持层或虚线调节关系。

## 图 2：文本证据构建图（text_evidence_pipeline.mmd）

### 论文中的推荐标题
结构化文本证据构建流程

### 图意
这张图用于突出次贡献，说明原始文本如何经过检索、趋势假设、质量评估和证据压缩，最终转化为：
- `text_evidence_vec`
- `trend_prior_text`
- `text events`

### 强调点
- 需要把“Stage-1 Retrieval”和“Stage-2 Retrieval”分开画。
- 要突出趋势假设在双阶段检索中的桥接作用。
- 质量评估和趋势字段抽取建议画成并行结构，最后汇聚到证据向量和趋势先验。

## 推荐配色

- 数值输入：蓝色系
- 文本输入 / 检索模块：橙色系
- 核心结构化处理：绿色系
- 扩散与输出：青蓝系
- 支持模块：灰色系

## 使用建议

### 如果你用 Mermaid
直接打开 `.mmd` 文件到 Mermaid Live Editor 中渲染。

### 如果你用 draw.io / PPT
建议按以下顺序重绘：
1. 先按模块分区搭框
2. 再补箭头方向
3. 最后补公式或短标签

### 如果你用于论文正文
- 图 1 放在第 2 章开头或 2.4 节前
- 图 2 放在第 2.3 节结构化文本证据构建部分
